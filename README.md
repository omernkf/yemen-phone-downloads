### باحث الأرقام اليمنية بالذكاء الاصطناعي

## 📱 مميزات التطبيق

- البحث باستخدام رقم الهاتف.
- البحث بالاسم بعد الموافقة على مشاركة جهات الاتصال.
- التعرف على شركات الاتصالات اليمنية.
- الوضع الليلي والنهاري.
- حفظ الأرقام والتواصل عبر تطبيقات المراسلة.
- الاستخدام دون الحاجة إلى تسجيل حساب.
